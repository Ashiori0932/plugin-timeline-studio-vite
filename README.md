# Timeline Studio 使用说明

Timeline Studio 是一个可以直接在浏览器里使用的可视化时间轴展示编辑器。你不需要会编程，也不需要安装任何软件，只要打开网页，就可以用拖拽和表单编辑的方式制作一组可以播放切换的展示页面。

在线访问：<https://ashiori0932.github.io/plugin-timeline-studio-vite/>

## 这个项目可以用来做什么？

你可以把 Timeline Studio 理解成一个“数据驱动的演示页面制作工具”：

- 一份数据里可以包含多页内容，例如第 1 页、第 2 页、第 3 页……
- 每一页都可以有标题、描述、图片、图表数据等字段。
- 画布上的文字、图片、图表组件会绑定这些字段。
- 当你在时间轴里切换页面时，画布会用同一套版式展示不同页面的数据。
- 完成编辑后，可以进入展示模式，让内容像演示文稿一样自动播放。

适合用于：

- 制作数据故事或行业观察页面；
- 制作活动大屏、信息看板或汇报展示；
- 快速测试一组数据在同一视觉模板下的展示效果；
- 将 JSON 数据整理成可播放、可切换的图文页面。

## 第一次打开页面会看到什么？

打开在线页面后，你会进入编辑模式。默认项目已经准备好了一组示例内容，你可以直接体验所有功能。

编辑模式主要由这些部分组成：

1. **顶部工具栏**：修改项目名、导入数据、导入项目、导出项目、进入展示模式。
2. **中央画布**：编辑展示页面的主要区域，所有文字、图片和图表都在这里摆放。
3. **左侧组件库 / 页面图层**：添加新组件，选择已有组件，拖动图层改变前后遮挡关系。
4. **右侧组件参数 / 画布参数**：修改选中组件的内容绑定、位置尺寸和样式参数。
5. **底部悬浮时间轴按钮**：展开完整时间轴，并切换当前正在编辑的数据页。

## 基本使用流程

如果你是第一次使用，可以按下面的顺序操作：

1. 打开在线页面。
2. 在画布上点击一个组件，例如标题、图片或图表。
3. 在右侧面板修改这个组件的内容绑定、位置尺寸或样式。
4. 点击画布底部的时间轴按钮，展开完整时间轴。
5. 点击时间轴里的不同卡片，查看同一版式在不同数据页下的效果。
6. 从左侧组件库添加更多文字、图片或图表组件。
7. 在左侧页面图层里拖动组件顺序，调整组件之间的前后遮挡关系。
8. 点击顶部的“展示”按钮，进入全屏播放预览。
9. 满意后点击顶部“导出项目”，保存你的项目文件。

## 顶部工具栏怎么用？

顶部工具栏位于页面最上方。

### 修改项目名称

中间的项目名称输入框可以直接编辑。你可以把默认名称改成自己的项目名，例如“年度业务数据展示”。

### 导入数据

点击“导入数据”后，可以选择一个 JSON 数据文件。

导入数据只会替换时间轴中的数据页，不会清空你已经摆好的画布组件和样式。

适合用于：

- 已经设计好版式，只想替换展示内容；
- 用同一个模板展示另一组数据；
- 测试不同数据对画面效果的影响。

### 导入项目

点击“导入项目”后，可以选择之前导出的项目文件。

导入项目会恢复完整项目，包括：

- 项目名称；
- 画布设置；
- 所有组件的位置、大小、样式；
- 时间轴数据。

### 导出项目

点击“导出项目”后，浏览器会下载一个 JSON 文件。

这个文件就是你的项目备份。以后可以通过“导入项目”重新打开。

### 进入展示模式

点击“展示”按钮后，会进入全屏展示模式。展示模式适合用于正式预览、汇报或投屏。

## 中央画布怎么用？

中央画布是你设计页面的地方。

### 选择组件

用鼠标点击画布上的文字、图片或图表，即可选中该组件。

选中后：

- 组件周围会出现选中框；
- 右侧面板会显示这个组件的参数；
- 你可以修改它的位置、尺寸、样式和数据绑定。

### 移动组件

选中组件后，按住鼠标拖动即可移动。

如果你想更精细地移动，可以在拖动时按住 `Alt`，这样会暂时关闭网格吸附。

### 调整组件大小

选中组件后，组件四角会出现调整手柄。

拖动角上的小圆点即可改变组件大小。

### 用键盘微调组件

选中组件后，可以使用键盘方向键移动组件。

- `←`：向左移动；
- `→`：向右移动；
- `↑`：向上移动；
- `↓`：向下移动；
- `Delete` 或 `Backspace`：删除所选组件。

### 缩放画布

在编辑模式下，先点击中央画布区域，再滚动鼠标滚轮，就可以放大或缩小画布。

缩放范围是 25% 到 400%。

如果你点击了左侧面板、右侧面板或时间轴，画布滚轮缩放焦点会取消，避免在操作面板时误缩放画布。

## 左侧组件库和页面图层怎么用？

左侧面板包含两个主要区域：组件库和页面图层。

### 展开和收起左侧面板

左侧面板边缘有一个箭头按钮。

- 面板展开时，点击箭头可以收起；
- 面板收起时，点击箭头可以重新展开；
- 收起后不会占用画布空间，只留下一个展开按钮。

### 添加组件

在“组件库”区域中，可以点击组件卡片添加组件。

内置组件包括：

- **文本组件**：用于展示标题、说明、标签等文字；
- **图片组件**：用于展示图片字段；
- **条形图组件**：用于用横向条形展示一组数值指标；
- **雷达图组件**：用于用 4-8 个维度展示一组指标，并在展示模式中播放数值变化动画；
- **进度组件**：用于展示播放进度相关效果。

点击组件卡片后，新组件会出现在画布上，并自动成为当前选中组件。

### 使用页面图层

“页面图层”区域列出了画布上的所有组件。

你可以：

- 点击某一行来选中对应组件；
- 查看组件绑定的字段；
- 拖动图层行来改变组件前后遮挡关系。

页面图层的规则是：

- 列表越靠上的组件，在画布上越靠前；
- 列表越靠下的组件，在画布上越靠后。

如果某个组件被另一个组件挡住，可以把它在页面图层里往上拖。

## 右侧组件参数面板怎么用？

右侧面板用于修改当前选中内容。

### 展开和收起右侧面板

右侧面板边缘也有一个箭头按钮。

- 面板展开时，点击箭头可以收起；
- 面板收起时，点击箭头可以重新展开；
- 收起后不会占用画布空间，只留下一个展开按钮。

### 选中组件时

当你选中画布上的组件后，右侧面板会显示该组件的参数。

常见参数包括：

- **数据绑定**：决定组件显示当前数据页里的哪个字段；
- **位置与尺寸**：修改组件的 X、Y、宽度、高度；
- **组件样式**：修改字号、颜色、圆角、对齐方式、图表颜色等；
- **复制组件**：复制当前组件；
- **删除组件**：删除当前组件。

### 没有选中组件时

如果你点击画布空白区域，右侧面板会显示画布和时间轴的项目级设置。

你可以修改：

- 画布背景颜色；
- 网格尺寸；
- 默认播放时长；
- 是否循环播放。

## 时间轴怎么用？

时间轴用于切换当前正在编辑的数据页。

### 展开时间轴

画布底部中央有一个悬浮按钮。点击它可以展开完整时间轴。

### 收起时间轴

完整时间轴顶部有一个扁平的向下箭头按钮。点击它可以收起时间轴，回到底部悬浮按钮状态。

### 切换当前页面

展开时间轴后，每一张卡片代表一个数据页。

点击某张卡片，画布会切换到对应的数据页。此时画布上的组件仍然保持原来的位置和样式，但显示内容会变成这张卡片对应的数据。

### 浏览更多页面

默认示例项目包含 10 个页面，页面较多时，时间轴可能无法一次显示全部卡片。

你可以把鼠标放在时间轴卡片区域，然后：

- 滚动鼠标滚轮，横向浏览更多卡片；
- 按住鼠标左右拖动，横向拖拽时间轴；
- 即使页面很多，时间轴下方也不会显示额外滚动条。

## 数据绑定是什么意思？

数据绑定可以理解为：告诉组件“你要显示当前页面里的哪一项内容”。

例如某一页数据中有这些字段：

```json
{
  "title": "先进制造正在重写增长曲线",
  "description": "从自动化产线到工业视觉，关键技术的渗透率持续提高。",
  "image": "https://example.com/image.jpg",
  "metrics": {
    "工业视觉": 84,
    "智能装备": 71
  }
}
```

那么：

- 文本组件可以绑定 `title`，显示标题；
- 文本组件也可以绑定 `description`，显示描述；
- 图片组件可以绑定 `image`，显示图片；
- 条形图或雷达图组件可以绑定 `metrics`，显示一组数值指标。

当你在时间轴中切换到另一页时，组件会读取另一页里同名字段的内容。

## 如何准备自己的数据？

如果你只想使用图形化界面，可以先从“导出项目”得到一个文件，再参考里面的数据结构修改。

最简单的数据文件可以像这样：

```json
{
  "items": [
    {
      "id": "page-01",
      "duration": 6000,
      "title": "第一页标题",
      "description": "第一页说明文字",
      "image": "https://example.com/1.jpg",
      "metrics": {
        "指标A": 80,
        "指标B": 65
      }
    },
    {
      "id": "page-02",
      "duration": 6000,
      "title": "第二页标题",
      "description": "第二页说明文字",
      "image": "https://example.com/2.jpg",
      "metrics": {
        "指标A": 72,
        "指标B": 91
      }
    }
  ]
}
```

说明：

- `items` 是页面列表；
- 每个 `{ ... }` 是一页；
- `duration` 是这一页在展示模式中的播放时长，单位是毫秒；
- `title`、`description`、`image`、`metrics` 都是可以被组件绑定的字段；
- 你可以增加更多字段，只要之后在右侧面板里选择对应绑定即可。

## 展示模式怎么用？

点击顶部“展示”按钮后，会进入全屏展示模式。

展示模式中：

- 页面会按照时间轴自动播放；
- 可以使用底部控制按钮播放或暂停；
- 可以切换上一页或下一页；
- 可以查看当前播放到第几页；
- 点击右上角“退出展示”可以回到编辑模式；
- 也可以按键盘 `Esc` 退出展示模式。

## 常见问题

### 为什么我滚动鼠标时画布在缩放？

这是因为你之前点击过画布，画布进入了滚轮缩放状态。

点击左侧面板、右侧面板或时间轴区域后，画布缩放焦点会取消。

### 为什么切换时间轴后，组件位置没有变化？

这是正常的。

Timeline Studio 的设计方式是：组件的位置和样式是一套固定模板，时间轴只切换每一页的数据内容。

### 为什么我导入数据后，有些组件没有显示内容？

通常是因为组件绑定的字段在新数据里不存在，或者字段类型不适合当前组件。

你可以选中组件，在右侧面板的“数据绑定”中重新选择字段。

### 图片为什么显示不出来？

请检查图片字段是否是可以访问的图片地址。

如果图片地址来自网络，需要确保该地址可以在浏览器中打开。

### 如何让某个组件显示在最前面？

在左侧“页面图层”中，把该组件拖到列表更靠上的位置。

### 如何保存我的作品？

点击顶部“导出项目”，下载项目 JSON 文件。

之后可以通过“导入项目”重新打开。
